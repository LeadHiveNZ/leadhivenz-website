# Photo slots: drop real photos here

Every page works without photos (blueprint-style placeholders show). Save a JPG with the exact
filename below and it appears automatically, with no HTML change needed. Then update that `<img>`'s `alt`
text (and gallery captions) so they describe the real photo.

Export: JPG, sRGB, quality ~75–80, long edge as listed, under ~400 KB each. No people's faces without consent;
no house numbers or number plates.
