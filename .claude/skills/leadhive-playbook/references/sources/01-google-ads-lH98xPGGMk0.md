This tutorial provides a complete step-by-step guide to configuring lead conversion tracking in Google Ads using Google Tag Manager (GTM) and a WordPress website (`coreysturf.com`, a mock lawn care business). The video is designed for digital marketers, business owners, and PPC managers who need to accurately track form submissions and phone calls generated by Google Ads campaigns. ### 3. CORE CONTENT

#### Step 1: Google Tag Manager (GTM) Setup on WordPress (00:50–03:00)
1. **Container Code Placement:** GTM requires placing two script code snippets on every website page (one in the `<head>` tag and one in the `<body>` tag) [00:50–01:15].
2. **Advanced Option Mentioned:** *Google Tag Gateway* (works with Cloudflare for advanced server-side data control) [01:19–01:30].
3. **WordPress Installation Method:**
   * Install and activate the free WordPress plugin **WPCode** (searched under `Code Snippets`) [01:40–02:05].
   * Navigate to `Code Snippets` > `Header and Footer` on the left sidebar [02:10].
   * Paste the GTM Header script into the **Header** box [02:25].
   * Paste the GTM Body script into the **Footer** box [02:28].
   * Click **Save Changes** [02:30].
4. **Tag Verification:** Use the free Chrome extension **Google Tag Assistant** to confirm that GTM (Container ID format `GTM-XXXXXXX`) and Google tags are loading properly on the site [02:35–03:00].

#### Step 2: Main Google Tag & Conversion Linker Configuration (03:00–10:20)
1. **Navigating Google Ads Goals:** Go to `Goals` > `Conversions` > `Summary` [03:10].
2. **Google Tag Setup in GTM:**
   * In Google Ads, find your AdWords Tag ID (format: `AW-XXXXXXXXX`) under `Data Manager` or `Edit data sources` [05:00–05:15].
   * Open GTM > Tags > **New Tag**.
   * Choose Tag Type: `Google Ads` > `Google Tag`.
   * Input Tag ID (`AW-XXXXXXXXX`) [05:25].
   * Set Trigger to `Initialization - All Pages` or `All Pages` [05:35].
   * Name: `Google Ads Tag (AW-...)` and click **Submit** > **Publish** [05:45–06:10].
3. **Setting Up Lead Form Tracking (Thank-You Page Redirect):**
   * In Google Ads: Click **+ Create conversion action** > **Conversions on a website** [06:30].
   * Goal Category: `Submit lead form` [06:40].
   * Goal Name: `Corey's Turf lead form` [07:00].
   * Optimization Action: `Primary action` (used for bidding optimization) [07:05].
   * Value: Set a conversion value (e.g., `$1` standard baseline, or higher values like `$100`, `$250`, or `$500` if assigning real lead values) [07:10–07:30].
   * Count: `One` per click [07:35].
   * Select manual setup with Google Tag Manager to obtain the **Conversion ID** and **Conversion Label** [07:50–08:15].
   * In GTM: Create Tag > Type `Google Ads Conversion Tracking` [08:05].
   * Input Conversion ID and Conversion Label [08:15].
   * Create Trigger: Click `+` > Trigger Type `Page View` > `Some Page Views` > Set condition `Page URL contains thank-you` (matching `coreysturf.com/thank-you`) [08:55–09:35].
4. **Installing Conversion Linker Tag:**
   * In GTM: Create Tag > Type `Google Ads` > `Conversion Linker` [09:40–09:55].
   * Trigger: `Initialization - All Pages` [09:58].
   * Save and Publish [10:05].

#### Step 3: Comprehensive Phone Call Tracking (10:20–18:00)
Frankosky details creating **3 distinct call conversion actions** to capture all call types without double-counting data:

1. **Calls from Ads (Call Extensions & Call Ads)** [11:10–12:00, 19:30–20:10]:
   * In Google Ads: Create conversion action > `Phone calls` > `Calls from ads`.
   * Set action to Primary optimization.
   * Tracks calls lasting over the default call duration threshold (typically 60 seconds).
   * *Note:* Linking a **Google Business Profile** (Location Asset) automatically tracks profile call extensions [12:40].
2. **Calls from Website Visits (Dynamic Phone Number Replacement)** [11:30–12:10, 13:45–15:30]:
   * In Google Ads: Create conversion action > `Phone calls` > `Calls from website visits`.
   * Enter Destination Number (e.g., `(843) 555-7823`) and exact Displayed Phone Number format as shown on the site [11:45–12:00].
   * In GTM: Create Tag > Type `Google Ads Calls from Website Conversion`.
   * Copy the exact Displayed Phone Number, Conversion ID, and Conversion Label out of the Google Ads event snippet [14:00–15:05].
   * Set Trigger to `Initialization - All Pages` [15:15].
   * Tracks phone calls exceeding 60 seconds via dynamic forwarding numbers [15:20].
3. **Mobile Click-to-Call (Mobile Button Clicks)** [11:45–12:30, 15:30–17:50]:
   * In Google Ads: Create conversion action > `Phone calls` > `Clicks on your number on your mobile website`.
   * Get Conversion ID and Conversion Label from snippet [16:20–16:40].
   * In GTM: Go to **Variables** > Enable all built-in **Click** variables (`Click URL`, `Click Target`, etc.) [15:40–16:10].
   * Create Tag > `Google Ads Conversion Tracking` > Input Conversion ID & Label [16:35–16:50].
   * Create Trigger > Trigger Type `Click - Just Links` > `Some Link Clicks` > Condition: `Click URL contains TEL` [17:00–17:30].
   * Name: `Mobile Clicks to Call` [17:50].

#### Step 4: Verification & Campaign Goal Integration (18:10–22:00)
1. **GTM Debugging:** Click **Preview** in GTM, enter the thank-you URL (`coreysturf.com/thank-you`), and inspect Tag Assistant to verify that tags fire correctly upon page load and button click [18:15–19:25].
2. **Campaign Settings:** Go to campaign `Settings` > `Goals` > Select `Use campaign-specific goal settings` [21:05].
3. **Select Goals:** Group and select `Submit lead forms` (`Corey's Turf lead form`) and `Phone call leads` (`Calls from ads`, `Calls from website`, `Click to call`) [21:15–21:35].
4. **Bidding Strategy Recommendation:** Start campaign with **Maximize Conversions** bidding, then transition to **Target CPA** once sufficient conversion data accumulates [21:40–21:55].

### 5. WARNINGS

* **Account Disapproval / Suspension Risk (04:40–04:55):** Avoid adding too many distinct root URLs to a single Google Ads account. Frankosky notes that putting multiple URLs into one ad account can trigger automated Google account suspensions or shutdowns.
* **Overcounting Mobile Click-to-Call Conversions (13:15–13:35, 17:35–17:50):** Mobile click-to-call triggers when a link is clicked, not when a phone call completes. It will overcount conversions, particularly in Performance Max campaigns or from non-mobile clicks where the user does not actually complete the call. Frankosky warns to use it cautiously or primarily in Search campaigns.
* **Phone Number Formatting Discrepancies (11:45–12:05):** When setting up website call tracking, the "Displayed Phone Number" entered in Google Ads must match the exact layout (parentheses, spacing, hyphens) on the website. If formatted differently, Google's dynamic number replacement script will fail to detect and swap the number.
* **Missing Conversion Linker Tag (09:40–09:50):** Failing to add a Conversion Linker tag set to fire on `All Pages` in GTM will break click attribution for Google Ads conversion tracking.
* **GTM Event Snippet Interface Updates (13:40–15:10):** Google Ads no longer provides a simple copy-paste GTM configuration tab for call tracking. Users must manually copy parameter string values directly out of the raw JavaScript event snippet.
